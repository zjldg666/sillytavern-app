# Sillytavern App 1.2.20

发布日期：2026-11-12。正式签名 Release APK，手机界面扩展 1.3.14。

## 本版变化

相较 GitHub 上一正式版 1.2.18，本版包含 1.2.19 与 1.2.20 的改进：

- **连接方案保护**：输入的新密钥尚未保存时，提示先连接；等待密钥写入和模型列表读取完成后，再允许保存或切换方案，降低迟到请求串用方案的风险。明确提示被方案排除、会沿用当前值的字段。
- **密钥名称更清楚**：已绑定密钥的标签跟随方案名称，共享密钥显示多个方案名；新密钥尚未绑定时显示“未绑定方案”。保留密钥 ID、值与激活状态。
- **新建会话保留旧记录**：新建前确认原会话保存成功，保存失败则取消新建；清除残留菜单状态，角色菜单与聊天菜单均可创建独立会话。
- **删除会话更可靠**：删除当前会话前关闭并取消待保存任务，避免已删记录重新出现；删除最后一段不自动重建空白会话，删除失败时明确提示。
- **减少重复加载**：角色列表使用缩略图；打开角色直接继续其上次选定会话，避免全量扫描；指定会话减少重复历史读取，最近列表合并请求并短时复用结果。

原版 SillyTavern 1.19.0、酒馆助手 4.12.0、提示词模板 1.17.9 的固定来源保持不变，没有修改上游核心源码。
