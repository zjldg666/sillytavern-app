# README 图片来源

更新日期：2026-11-10。项目展示名称为 **Sillytavern App**。

## 原创生成素材

以下四张插画使用用户授权的当前 API 端点，通过未经修改的官方 imagegen CLI 调用 `gpt-image-2` 生成，质量参数为 `medium`。未使用第三方角色卡、参考人物照片或用户私有素材。封面标题是生成后单独排版的文字。

- `tavern-cover.webp`：雨夜酒馆与书房，1599 × 900；加入项目名和简介。
- `lin-portrait.webp`：林间来信的书店店主，640 × 640。
- `star-portrait.webp`：星际漫游的领航员，640 × 640。
- `night-portrait.webp`：夜航笔记的写作者，640 × 640。

完整生成提示词保存在 [generation-prompts.jsonl](generation-prompts.jsonl)。封面生成时项目尚名 Jiuguan，最终排版已改为 Sillytavern App。请求尺寸为封面 1536 × 1024、角色 1024 × 1024；端点实际返回封面 1672 × 941、角色 1254 × 1254。发布素材等比例缩小并转为 WebP，四张合计约 490 KiB。

这些图片是概念插画和虚构角色肖像，仅用于 README 与独立演示页，不是内置角色卡，也不代表 APK 内提供这些角色或故事。图片已逐张打开检查。

## 浏览器截图

`demo-chat-light.png` 与 `demo-chat-dark.png` 从仓库 `docs/demo/index.html` 实际渲染截图。浏览器视口 390 × 844、像素比例 2；图片尺寸为 780 × 1688。

两张截图展示独立 README 前端的白天 / 黑夜模式，头像采用上述原创生成素材，对话是为本项目编写的合成内容。页面交互不调用模型 API、不读取个人数据。它们不是 Android 实机截图，也不作为 APK 验收证据。

本次已检查 320 / 390 / 768 / 1280px 下的两种主题：无横向溢出，头像加载成功、输入框可见；主题切换、会话切换、发送预置回复与 Escape 关闭弹窗正常。无页面脚本错误或外部网络请求。检查后重新查看了发布截图。

重新截图时在浏览器打开演示页，选择“林间来信”，使用上述视口；黑夜模式通过页面右上角切换或添加 `?theme=dark`。

此前采集的第三方角色卡和个人设置截图不在公开文档内。APK 检查范围见对应发布说明，历史记录不因文档换图或项目更名而改变。
