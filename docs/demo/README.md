# README 聊天演示

直接在浏览器打开 `index.html`。这是零依赖、无外部资源的静态演示前端，与 Android App 代码分开。

- 白天 / 黑夜切换，暖白与暖炭黑配色，琥珀色强调。
- 三段原创合成对话：林间来信、星际漫游、夜航笔记。
- 三位 AI 生成的原创角色肖像，图片随仓库提供，离线加载；不使用第三方角色卡。
- 输入、快捷回复、会话选择与说明弹窗可以操作。
- 发送内容只在页面内存中显示，回复为预置文本；不调用模型，不保存私人数据。
- URL 加 `?theme=dark` 可直接打开黑夜模式。

本页面用于 README 展示，不是 App WebView 页面或功能验收替代品。不得把本页面截图标为真实 Android 运行截图。

2026-11-10 已检查 320 / 390 / 768 / 1280px 无横向溢出，消息输入可见、主题切换、会话切换、发送预置回复及 Escape 关闭弹窗；浏览器运行中无 HTTP 外部请求。
